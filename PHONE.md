# Запуск с телефона: Telegram-бот + content plan + автоматизация

Этот проект (форк [bekhruztbx/ai-creative-team](https://github.com/bekhruztbx/ai-creative-team)) добавляет:

| Что | Где | Как пользоваться с телефона |
|---|---|---|
| **Дневной планировщик из Telegram-чата** | `tgbot/bot.py` | Бот читает ваши группы, вытаскивает задачи (uz / ru / en) и каждое утро присылает расписание дня |
| **Timetable на неделю** | `/week` | Команда боту |
| **Content plan** | `/plan <тема> [дней]` + skill `planner` | Команда боту или Claude Code |
| **Бизнес-автоматизация** | `/every …` + skill `ops` | Повторяющиеся задачи и напоминания |
| **Новые skills для Claude Code** | `.claude/skills/timetable`, `planner`, `ops` | Claude Code в приложении Claude |

Интерфейс на телефоне — это сам Telegram. Бот работает на любом устройстве, которое включено: на Android-телефоне (Termux), на старом ноутбуке или на дешёвом VPS.

---

## Шаг 1. Создать бота (2 минуты, в Telegram)

1. Откройте **@BotFather** → `/newbot` → придумайте имя → скопируйте **токен**.
2. **Важно для чтения групп:** `@BotFather` → `/setprivacy` → выберите бота → **Disable**. Без этого бот в группе видит только команды.
3. Добавьте бота в рабочие группы. Бот видит только сообщения, пришедшие **после** добавления. Старую историю можно импортировать (шаг 4).

## Шаг 2а. Запуск на Android (Termux)

1. Установите **Termux** из F-Droid (версия из Google Play устарела). Для фоновой работы также поставьте **Termux:API**.
2. В Termux:

```bash
pkg install -y git
```

```bash
git clone https://github.com/Risqulov06/ai-team
```

```bash
cd ai-team
```

```bash
bash setup-termux.sh
```

Первая установка идёт 10–20 минут: собирается `pydantic-core`.

3. Впишите токен:

```bash
nano .env
```

Заполните `TELEGRAM_BOT_TOKEN=...`. Сохранение: Ctrl+O, Enter, Ctrl+X.

4. Запустите бота в фоне:

```bash
bash tgbot/run.sh
```

5. В настройках Android отключите для Termux **оптимизацию батареи**, иначе система «усыпит» бота.

> iPhone: на iOS нельзя держать фоновый Python-процесс. Запускайте бота на VPS или компьютере (шаг 2б), а с iPhone им пользуйтесь через Telegram.

## Шаг 2б. Запуск на сервере / компьютере (Linux, macOS, VPS)

## Шаг 3. Настроить в Telegram

1. Напишите боту `/whoami` и впишите свой ID в `.env` → `ALLOWED_USER_IDS=...`, чтобы командами пользовались только вы. Перезапустите бота: `tmux kill-session -t tgbot`, затем `bash tgbot/run.sh`.
2. В чате, куда хотите получать утренний план (личка с ботом или группа): `/here`.
3. Время утреннего отчёта: `/settime 07:30`.

## Команды

| Команда | Что делает |
|---|---|
| `/today`, `/tomorrow` | План дня: задачи с временем стоят на своих местах, остальные распределяются по свободным окнам рабочего дня, срочные первыми |
| `/week` | Timetable на 7 дней |
| `/tasks`, `/done 3` | Открытые задачи, отметить выполненной |
| `/add ertaga 15:00 mijoz bilan uchrashuv` | Добавить задачу вручную (можно ответом на сообщение) |
| `/scan` | Прямо сейчас вытащить задачи из новых сообщений (утром это происходит само) |
| `/plan qahvaxona 14` | Content plan на 14 дней; каждый день попадает в timetable как задача на подготовку |
| `/every weekdays 18:00 Kassa hisoboti` | Повторяющаяся задача (`daily`, `weekdays`, `mon,thu`…) |
| `/recurring`, `/unevery 2` | Список повторяющихся задач / удалить |

Также каждые 5 минут бот напоминает о задачах с конкретным временем за 15 минут до начала.

## Учёт расходов Uzcard / Humo

- **Android + SMS (автоматически).** В `.env` поставьте `SMS_AUTO_IMPORT=1`, дайте Termux:API разрешение на SMS. Каждые 15 минут бот читает новые SMS от банков и присылает «💳 Yangi operatsiyalar».
- **Уведомления в Telegram** (HUMO bot, CardXabar): просто **пересылайте** их боту в личку, и он сам распознает сумму, карту, магазин и категорию.
- Наличные: `/xarajat 25000 taksi`, `/xarajat 150k kafe`. Доход: `/kirim 3mln oylik`.
- Отчёт: `/hisobot today`, `/hisobot week`, `/hisobot month`. Вчерашние расходы также приходят в утреннем плане.
- Данные хранятся только на вашем устройстве (`out/money/`), от карты сохраняются лишь последние 4 цифры.

## AI-агент в Telegram (Claude Code на телефоне)

Пишете боту в личку обычным текстом: «bugun kim nima yozdi?», «Ali bilan nima kelishdik?», «haftalik content plan tuz». Бот передаёт сообщение в **Claude Code** (по вашей подписке Claude, без API-ключа), и тот отвечает, используя skills и агентов этого репозитория. Ваш собственный Telegram он видит через MTProto (Telethon), как ваш аккаунт: читает сразу, а **любое действие** (написать, сторис, профиль, боты) только предлагает — бот присылает запрос с кнопками ✅ / ❌ / ⏰ и делает это лишь после вашего ✅ (подробнее ниже).

У Claude Code нет сборки под Android, поэтому он работает в Ubuntu внутри Termux (proot-distro). Root не нужен, потребуется около 1.5 ГБ.

```bash
bash setup-agent.sh
```

Дальше три шага, их скрипт покажет в конце:
1. `bash tgbot/claude-proot.sh`: войдите в аккаунт Claude, затем `/exit`.
2. На https://my.telegram.org → **API development tools** получите `api_id` и `api_hash`, впишите их в `.env` (`TG_API_ID`, `TG_API_HASH`) и выполните `python3 tgbot/userbot.py login` (код придёт в Telegram).
3. Перезапустите бота и напишите ему `/ai`: он покажет, что подключено.

| Команда | Что делает |
|---|---|
| обычный текст | вопрос агенту; разговор продолжается между сообщениями |
| `/new` | начать новый разговор |
| `/ai` | состояние агента и подключения Telegram |
| `/sync` | прямо сейчас сохранить новые сообщения из ваших чатов (само по себе происходит каждые 10 минут) |
| `/ai <buyruq>` | любое дело в вашем Telegram: «Aliga yoz…», «guruhga yoz…», «storis qo'y…», «bio ni o'zgartir…», «@bot ga /start yubor» |
| `/navbat` | действия, которые ждут вашего ✅ |
| `/kotib` | секретарь прямо сейчас готовит ответы на входящие сообщения по вашему плану |
| `/reja` | AI составляет ваш план на сегодня |
| `/ishchi @user Ism 09:00`, `/ishchilar`, `/ishchi_ochir 2`, `/keldi Ali`, `/davomat` | сотрудники и посещаемость |

### Ruxsat (разрешение) на каждое действие

Агент, секретарь (`kotib`) и контроль сотрудников (`nazoratchi`) ничего не делают сами — они кладут действие в очередь (`inbox/telegram/actions/`, MCP-сервер `telegram` → `tgbot/tg_mcp.py`). Бот присылает вам: что, кому, текст и причину, с кнопками **✅ Ruxsat / ❌ Rad / ⏰ Keyinroq**.
- Не ответили — бот спросит снова через час (`ASK_EVERY_MIN`), и так до 24 раз (`ASK_MAX`).
- Если это сообщение в чат, а вы **сами написали в этот чат** после запроса — задача закрывается: вы сделали её сами.
- Если какие-то типы хотите без вопросов (например, только боты): `TG_AUTO_APPROVE=bot`.

**Секретарь** каждые 30 минут в рабочее время (`WORK_START`–`WORK_END`) смотрит, кто вам написал и ждёт ответа, и предлагает ответ по вашему плану дня. Выключить: `AUTO_REPLY=0`.

**Сотрудники**: за 15 минут до начала работы бот предлагает отправить напоминание, через 30 минут спрашивает у тех, кто не написал «keldim», причину. Причины видны в `/davomat`, вечером (`WORK_END`) приходит итог дня.

Осторожно: Telegram ограничивает аккаунты за массовые сообщения незнакомым людям. Не одобряйте десятки одинаковых сообщений подряд.

Агент работает только для ID из `ALLOWED_USER_IDS`, потому что он запускает команды на телефоне. Файл входа в Telegram лежит в `.secrets/` (в git не попадает): это полный доступ к вашему аккаунту, никому его не передавайте. Отключить доступ: Telegram → Настройки → Устройства → завершить сеанс «ai-team». Каждый ответ агента расходует лимиты вашей подписки Claude.

## Монтаж Reels прямо на телефоне (Android)

Бот делает то же, что агент **montaj** (skills `reel` + `pixel`): вырезает паузы и «um/uh», переводит видео в вертикаль 9:16, добавляет субтитры по 3 слова (произносимое слово жёлтое) и обложку, а затем присылает готовый Reel обратно в чат. Ничего не публикуется: проверяете и выкладываете сами.

**Установка (один раз, ~10 минут, после `setup-termux.sh`):**

```bash
bash setup-montaj.sh
```

Скрипт ставит ffmpeg, numpy и pillow, собирает [whisper.cpp](https://github.com/ggml-org/whisper.cpp) (распознавание речи прямо на телефоне, без интернета) и прописывает `WHISPER_CPP` и `WHISPER_CPP_MODEL` в `.env`. Android спросит доступ к файлам: разрешите. Модель по умолчанию `small` — многоязычная, для узбекской и русской речи (также вперемешку). Лучшее качество для узбекского — ключ `ELEVENLABS_API_KEY` в `.env` (облако). Другие размеры модели:

```bash
bash setup-montaj.sh small
```

Язык в `.env`: `WHISPER_LANG=auto` (узбекский + русский, по умолчанию), или `uz`, `ru`. Перезапустите бота:

```bash
tmux kill-session -t tgbot
```

```bash
bash tgbot/run.sh
```

**Как пользоваться:**

| Что | Как |
|---|---|
| Видео до 20 МБ | Отправьте боту в личку. Подпись к видео станет заголовком и текстом обложки (первые 3 слова) |
| Большое видео | Сохраните в «Загрузки» и напишите `/edit ~/storage/downloads/video.mp4` (так обходится лимит Telegram в 20 МБ) |
| Клипы из `inbox/` | `/edit` покажет список, `/edit 1` смонтирует первый, `/edit 1 \| UCH SO'Z MATN` задаст текст обложки |

Результат лежит в `out/<клип>/`: `edit.mp4`, `cover.jpg`, `captions.srt`, `notes.md`. Исходник переносится в `done/` и не удаляется. Длина (45 с) и цвет (#FFD400) берутся из `brain/memory.jsonl` (Brand rules). Поменять их можно в `.env` через `EDIT_MAX` и `EDIT_COLOR`. Минутный клип монтируется на телефоне примерно 3–8 минут; одновременно идёт только один монтаж.

## Claude (точнее) или правила (бесплатно)

- **Без ключа** бот распознаёт задачи по ключевым словам (kerak, uchrashuv, ertaga, soat 10 da / нужно, завтра, в 15:30 / meeting, tomorrow…) и строит план по шаблону.
- **С `ANTHROPIC_API_KEY`** в `.env` задачи из переписки вытаскивает Claude: понимает контекст, сокращает заголовки, определяет, кто исполнитель. Content plan он пишет под вашу тему. Если API недоступен, бот сам переключается на правила.

```bash
python3 tgbot/cli.py import inbox/result.json
```


## Claude Code с телефона (skills `timetable`, `planner`, `ops`, `reel`…)

В приложении Claude (iOS / Android) откройте **Code**, выберите этот репозиторий и пишите, например:

- *«Telegram xabarlaridan bugungi rejani tuz»* → skill `timetable`
- *«Kafe uchun 2 haftalik content plan»* → skill `planner`
- *«inbox/biz dagi jarayonlarni avtomatlashtir»* → skill `ops` (выдаёт готовые команды `/every` для бота)

Облачная сессия не видит файлы бота на телефоне: `inbox/telegram` в git не попадает, так как переписка приватная. Поэтому в Claude Code лучше работать с экспортом чата, а повседневный план брать у бота.

## Где лежат данные

- `inbox/telegram/*.jsonl` — сохранённые сообщения (в git не попадают)
- `out/timetable/tasks.json`, `out/timetable/<дата>.md` — задачи и планы дней
- `out/plan/*.md` — content plans
